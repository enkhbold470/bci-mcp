# Contributing

Contributions are welcome: bug reports, feature requests, device backends, docs and code.

- **Issues:** open one at https://github.com/enkhbold470/bci-mcp/issues. Questions and feedback are welcome there too.
- **Pull requests:** see [docs/contributing.md](docs/contributing.md) for setup, how to run the hardware-free test suite (`ruff check src tests && python -m pytest`), and how to add a device backend.
- **Support:** the maintainer reviews issues and PRs, usually within a week.
- **Releases:** tagged `vX.Y.Z`; each tag publishes to PyPI and npm. Changes are listed in [docs/changelog.md](docs/changelog.md).
