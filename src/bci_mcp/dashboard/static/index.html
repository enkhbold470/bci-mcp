First 15 minutes: try BCI-MCP without a headset

Use a synthetic signal to explore the dashboard, neurofeedback, recording, and replay.

  1. Start the synthetic dashboard. In a terminal, run: 
    bci-mcp dashboard --device synthetic://

    Open http://127.0.0.1:8000. If you started this dashboard with another device, restart it with the command above to follow along.

  2. Watch the bars. After a short warm-up, the metric bars and relative frequency-band columns below update as the synthetic signal changes. The columns are scaled relative to the largest band, not an absolute EEG measurement.
  3. Try neurofeedback. Leave the dashboard running and open a second terminal. Run a 30-second focus session: 
    bci-mcp neurofeedback --device synthetic:// --metric focus --target 0.7 --seconds 30

    Watch the current score and time in the target zone, then read the summary. This uses a separate synthetic stream; it does not control the dashboard.

  4. Record a sample. In the second terminal, run: 
    bci-mcp record --device synthetic:// --seconds 30 --out session.npz

    This records a new synthetic stream to session.npz in that terminal's working directory, not the dashboard stream.

  5. Replay it. From the same directory, run: 
    bci-mcp play session.npz

    The recording loops in the terminal brain-meter. Press Ctrl+C to stop; use Ctrl+C in the dashboard terminal to stop it too.

Synthetic data is simulated, not your brain activity. Focus and calm are heuristic band-power proxies, not SSVEP classifiers or clinical measurements.

Synthetic signal explorer

Change the simulated mix and watch the band columns below. Lower values add alpha; higher values add beta.

What happens when I move the slider?

The slider changes the amplitudes of two simulated waves: lower values make the 10 Hz alpha wave stronger and the 20 Hz beta wave weaker. Higher values do the opposite. The simulated 6 Hz theta wave stays the same.

The slider value is a mix setting from 0 to 1, not the measured beta/alpha power ratio. The band columns and focus score are calculated from the resulting signal, and may take a few seconds to catch up.

Changes affect this synthetic stream only. Allow a few seconds for the analysis window to update; the setting does not measure or change your mental state.

What does the focus / concentration ratio mean?

Raw focus ratio = beta power ÷ (alpha power + theta power). The current ratio is waiting for signal….

The focus bar above maps this ratio to a score between 0 and 1; it is not the raw ratio. More beta relative to alpha and theta tends to raise the score. Moving the synthetic slider changes the signal used in this calculation.

This is a heuristic proxy, not a direct measurement of concentration or a clinical test. Synthetic data does not represent your brain activity.

Heuristic band-power proxies — not clinical, diagnostic, or event-level EEG. Welch PSD averages transients out (no ERPs, spindles, or bursts). Weight readings by confidence and treat an unreliable signal as untrustworthy.
